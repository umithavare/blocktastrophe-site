Privacy Policy

Blocktastrophe Uploader. Last updated: November 17, 2026.

Blocktastrophe Uploader is a private tool that the Blocktastrophe YouTube channel uses to upload its own videos. It is not offered to the public and has a single user: the channel owner.

What the tool accesses

With the channel owner's permission, given through Google sign-in, the tool uses the YouTube Data API with these permissions:

  • Upload videos (youtube.upload): to upload the channel's own videos and set their thumbnails.
  • View the YouTube account (youtube.readonly): to confirm that it is connected to the Blocktastrophe channel and to check the processing and privacy status of the videos it uploaded. The channel also uses this access to read public information about public YouTube videos, such as titles, lengths and view counts, for its own content research.
  • View YouTube Analytics reports (yt-analytics.readonly): to read the channel's own audience retention and view statistics, so that later videos can be improved. Only the channel's own reports are read.
  • Google Drive, only files the tool creates (drive.file): to place the channel's own finished videos in its Drive so they can be shared to the channel's own Instagram and TikTok accounts. The tool cannot see any other file in the Drive.

The tool does not access any other private Google data, and it never accesses anyone else's account.

How the data is used and stored

  • Videos are always uploaded as private. The tool never publishes a video or changes its privacy setting.
  • The sign-in tokens are stored only on the channel owner's own computer. They are sent only to Google, to make the API calls described above.
  • The tool keeps a local log of its uploads (video ID, file checksum, title and status) on the owner's computer.
  • Public video information read for research is kept for at most 30 days, unless it is refreshed.
  • The owner runs the tool with the help of an AI assistant (Claude, by Anthropic), which can see upload results such as video IDs and statuses. It never sees the sign-in tokens.
  • No data is sold, shared for advertising, or used for analytics.

Removing access and data

The owner can delete the locally stored tokens and log at any time, and can remove the tool's access to the Google account at myaccount.google.com/permissions.

YouTube and Google terms

This tool uses YouTube API Services. Using it means agreeing to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Contact

Questions about this policy can be sent to blocktastrophe.studio@gmail.com or to the Blocktastrophe channel on YouTube.
