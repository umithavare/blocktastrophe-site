Blocktastrophe Uploader

Blocktastrophe Uploader is a private tool that the Blocktastrophe YouTube channel uses to upload its own videos. Every video is uploaded as private, so the channel owner can review it in YouTube Studio before deciding whether to publish it. The tool never publishes videos and never changes their privacy setting.

The tool uses YouTube API Services (the YouTube Data API) with the channel owner's permission. It is not offered to the public and has a single user: the owner of the Blocktastrophe channel.
